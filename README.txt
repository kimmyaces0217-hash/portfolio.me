TONY NYAIRO — DATA ANALYST PORTFOLIO
======================================
PAGES: Home, About, Projects, Experience, Skills, Contact.
FILES: css/style.css; js/main.js; js/site-config.js; js/projects.js; replaceable assets in img/.

RUN:
1. Extract the ZIP and open the folder in VS Code.
2. Install the Live Server extension.
3. Right-click index.html > Open with Live Server.

CUSTOMISE:
- Portrait: img/tony-hero.png. Both Home hero and About page use this image.
- Personal details, social links and CV path: js/site-config.js.
- Put your CV PDF at img/tony-nyairo-cv.pdf or update the CV links.
- Projects, descriptions, tools, preview image paths and Google Sheets URLs: js/projects.js.
- Replace sample project SVG previews in img/projects/ with your own screenshots.
- Replace logo and icon SVGs in img/icons/ with your own SVG/PNG assets; update paths if filenames change.
- Replace placeholder social URLs, email and contact details before publishing.
- Confirm the home page statistics and add verified employment dates/job titles before publishing.

GOOGLE SHEETS:
Paste each project workbook's share URL into its sheetUrl field in js/projects.js.
Set the Sheet's sharing permissions so your intended visitors can view it.
Each project card opens its own link in a new tab. If a link is still a placeholder,
the site displays a reminder rather than opening a broken URL.

The contact form uses mailto and opens the visitor's email application; it has no
backend. Project overview graphics are sample placeholders, ready to replace.
